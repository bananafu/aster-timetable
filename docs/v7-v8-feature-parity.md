## 已確認的 V8 Timetable 政策

「複製教師課表」只複製名稱與教師設定，不複製 Lesson、OneOff、Change、Event 或 Progress。刪除前如有任何有效引用必須阻擋，先由使用者處理引用；不得沿用 V7 的課程複製或級聯刪除行為。舊版規格中描述的完整課表複製只適用 V7。
